# Foodmach Integration
Contains the Talend Studio jobs, integration table DDLs, and landing table DDLs for the Netsuite to TotalETO integration, and the EmploymentHero to FMDW integration.

## Repository Structure

```
.
├── TEST/
├── DDLs/
├── .gitignore
└── README.md
```

## TEST

This folder contains the Talend jobs. Do not edit this from Github.

## DDLs

Contains the DDLs for:

- The **integration** tables for Purchase Orders, Item Receipts, Inventory Adjustments, Vendors
- The **Employment Hero landing** tables in the FMDW data warehouse
